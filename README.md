# Windows IT Support & Troubleshooting Home Lab

# Overview
This project documents a hands-on Windows 10 virtual machine lab designed to practice foundational IT support, system administration, user account management, and network troubleshooting skills.

# Lab Environment
- **Operating System:** Windows 10 Pro (Virtual Machine)
- **Virtualization:** Oracle VirtualBox
- **Tools:** Command Prompt, PowerShell, Event Viewer, Windows User Account Control (UAC), and network diagnostic utilities

# Skills Demonstrated

# Windows Administration
- Created and managed local user accounts.
- Compared standard user and administrator permissions.
- Configured shared folders and tested access permissions.
- Verified Windows version and system information.

# Network Troubleshooting
- Used `ipconfig` to inspect network configuration.
- Used `ping` to test network connectivity.
- Used `nslookup` to investigate DNS resolution.
- Simulated a DNS configuration issue, diagnosed the problem, restored the correct configuration, and verified connectivity.

# Command-Line Tools & System Diagnostics
- Used Command Prompt and PowerShell for system information and troubleshooting.
- Inspected running processes and resource usage.
- Used Event Viewer to review Windows system events.

# Troubleshooting Process
I tested network connectivity and DNS resolution, investigated a simulated DNS issue, restored the appropriate DNS configuration, and verified that name resolution worked again. I also tested user permissions and shared-folder access to understand how Windows controls access to resources.

# Project Evidence
Screenshots and supporting documentation demonstrate the configuration steps, diagnostic commands, troubleshooting process, and verification results.

# Purpose
This project was completed independently as part of my preparation for entry-level IT support roles. It demonstrates practical familiarity with Windows administration, basic networking, troubleshooting methodology, and system diagnostics.
